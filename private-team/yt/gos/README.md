# GOS™ — The GovCon Operating System
### Version 0.1 · Started July 18, 2026

> **Operating Principle #1:** *A company that learns faster than its competitors eventually becomes impossible to compete with.*

**Purpose:** build the world's greatest media company for government entrepreneurs by continuously improving how opportunity is discovered, communicated, and acted upon.

This is a **repository, not a pile of files** — think GitHub for the company. The question is never *"where do we put this?"* but **"which module does this improve?"** GOS is the **single source of truth**: every new idea is incorporated here under the correct module, never in a new chat or standalone doc.

We run it like software — **everything is versioned.** People say *"Did you update GOS?"*, not *"Did you update the document?"*

---

## Start here
1. **[The GovCon Giants Constitution](./00_vision/constitution.md)** — why we exist, what we believe, how we decide, what we never compromise, how we define success, how we improve. *Every decision references it.*
2. **[Foundations](./00_vision/foundations.md)** — mission, first principle, the Laws, the Flywheel, the Systems at a glance.

## The Decision Filter
Every decision answers five questions — **yes to at least four → we move:**
1. Reveal an opportunity? 2. Build belief? 3. Create a government entrepreneur? 4. Improve the operating system? 5. Learn something even if it fails?

## Repository structure
```
GOS/
├── 00_Vision      — Constitution · Mission · Manifesto · Core Beliefs · Company Definition
├── 01_Method      — the Laws · Principles · the Systems (Story DNA · Compass · Opportunity · Hook Engine…)
├── 02_Production  — Producer · Editor · Thumbnail · Title · Shorts · QA · the Editor's Dashboard™
├── 03_Library     — Story DB · Opportunity DB · Hook / Thumbnail / Title Libraries · Analytics
├── 04_R&D         — Experiments · Learning Journal · Decision Journal · Failed Assumptions
├── 05_Company     — Hiring · Meetings · Culture · KPIs · AI
└── 99_Discoveries — one page per validated discovery (the compounding IP)
```
*Nothing here is about YouTube. Everything is about building a company.* **Frameworks → Systems:** the tools are now Systems (Story DNA System™, Hook Engine System™, Editing System™, Learning System™) — how GovCon Giants operates, not a toolbox.
