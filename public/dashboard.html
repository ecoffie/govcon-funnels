      Definitions

      • Traffic– Where visitors come from: ads, organic search, social links, email.
      • Funnels– Landing pages and flows that capture leads or send them to upsell/downsell.
      • Upsell / Downsell– Post-signup offers (e.g. Pro Member Group upsell, downsell to thank-you).
      • Product / Download– What they get: product access, PDFs, handouts, course access.
      • Confirmation email / Follow-up sequence– Automated email after signup and any drip or follow-up sequence.
      • Email or phone reach out– Manual outreach (cold or warm) to book meetings.
      • First meeting– Initial call or meeting with a lead.
      • Sale / Schedule a second meeting– Outcomes of the first meeting: close the sale or book a follow-up.

      How Lead Capture Works

      All forms use the LeadForm component which posts to /api/lead:

      1. User fills out form (name, email, phone)
      2. Form posts to /api/lead with source tag
      3. API creates/updates contact in Go High Level CRM
      4. API sends Slack notification to team channel
      5. API sends confirmation email (if configured)
      6. User redirects to thank you/upsell page

      🧪 Testing Lead Automation

      To test if leads are flowing correctly:

      1. Fill out any form with test data (use unique email like test-{source}@example.com)
      2. Check Slack channel for notification (should appear within seconds)
      3. Check Go High Level for new contact with correct source tag
      4. Check email inbox for confirmation (if email configured for that source)

      View Vercel function logs at Vercel Dashboard → Project → Logs for debugging.
